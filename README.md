# porete-mirouer-corpus
A computational corpus and network analysis of Marguerite Porete’s *Mirouer des simples âmes anienties*.
This release contains the corpus, processed textual data, network-analysis
artifacts, and supporting computational materials used to examine lexical
patterns, character interactions, and structural relationships within the text.
